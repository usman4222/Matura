# MATURA

A 90-day C-section scar-care system: 12 pre-cut medical-grade silicone sheets, guided protocol and premium storage pouch.

## Development

You need Node.js and npm (or bun/pnpm/yarn) installed on your system.

### Installing Dependencies

```sh
npm install
```

### Running the Development Server

```sh
npm run dev
```

### Building for Production

```sh
npm run build
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
